# 洛伦兹实验室 · 电磁小球


一款冷黑白风格的三维物理解谜游戏。观察目标、障碍和场线，在发射前调整小球的方向或初速度，利用电场、磁场、重力与墙面反弹，让小球在 30 秒模拟时间内抵达目标。


游戏包含 **3 段新手教学 + 28 个正式挑战，共 31 关**。第一段练水平方向，第二段练仰角，第三段练提高速度以克服反向电场；之后的关卡逐步加入更多空间路线与电磁场源。关卡顺序解锁，通关后可以直接进入下一关。白色轨迹记录本次尝试，灰色轨迹保留上次路线，方便观察和调整。

## 基本操作


- 拖动外侧或内侧圆环：调整水平角或仰角；拖动白色方块：调整初速度。每关只开放相关控制。
- `Space` 发射；`R` 重新尝试；`P` 暂停或继续；`L` 显示或隐藏辅助场线。
- 按住右键拖动观察场景；滚轮调整距离；`F` 返回跟随视角；`Esc` 打开或关闭设置。


辅助场线在首次启动时默认显示。通关评分同时考虑用时、反弹次数和可选奖励球；游戏会保存最高分、最快时间及挑战记录。
